## How this Netlify site is deployed

No linked Git repo was found. Local Netlify state (`~/.netlify/state.json`) only has an unrelated site id. Treat production as a **manual drag-drop** (or `ntl deploy --prod --dir=.`) onto site `wisdomtwin-deck`.

To add the filename aliases on Netlify (so the 404 paths below start working):

1. Open https://app.netlify.com
2. Open site `wisdomtwin-deck`
3. Deploys → drag this entire folder onto the deploy drop zone
4. Confirm these return HTTP 200 and the same MD5:
   - /WisdomTwin-Investor-Deck.pdf
   - /WisdomTwin-E4-Investor-Deck-2026-08-10.pdf
   - /WisdomTwin-E4-Investor-Deck-2026-08-11.pdf
   - /deck.pdf
   - /wisdomtwin-deck.pdf

Do not replace the HTML deck viewer at `/` unless you intend to. `index.html` in this folder is a snapshot of the live Netlify HTML as of 2026-08-14.
